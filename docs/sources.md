# Sources and design choices

The package contains reusable research-writing guidance and original synthetic examples.

Version 0.2.0 preserves the full reusable source material through [the reference index](../skills/research-writing/references/transfer-index.md).
The transfer covers the method, seven rule chapters, six critic guides and all structured templates.
It includes every coded feedback lesson and synthetic adaptations of the teaching cases.
The private audit maps every source file, section and feedback identifier to its destination or retention reason.
Current author instructions take precedence over older notes where they conflict.
The [writing standard](../skills/research-writing/references/writing-standard.md) records those decisions.
The [author-style guide](../skills/research-writing/references/author-style.md) preserves useful structural techniques from the longer style reports.
Institutional rules, private history and local extraction code remain outside the public skill.

The writing profile draws on George Orwell's six rules and William Zinsser's principles of clarity and brevity.
It also uses simplified technical English as a practical style guide.
It makes no claim of formal certification under ASD-STE100.
The author added rules against corrective juxtaposition and formulaic AI prose.
The detailed anti-slop checks also draw on the author's supplied MIT-licensed Stop Slop notes by Hardik Pandya.
The package adapts their patterns to scientific prose and preserves meaningful qualifiers.

The [Agent Skills specification](https://agentskills.io/specification) defines the portable directory format.
[OpenAI's skill documentation](https://learn.chatgpt.com/docs/build-skills) describes skill packaging.
[Claude Code's skill documentation](https://code.claude.com/docs/en/skills) describes discovery and invocation.

[Autoresearch](https://github.com/uditgoenka/autoresearch) informed the interest in maintained packages and recorded iterations.
This project uses original code and instructions.
Its writing procedure combines deterministic checks with scientific and editorial judgement.
